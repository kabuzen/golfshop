Pengelolaan editor

Undang editor melalui Supabase Dashboard → Authentication → Users → Invite user. Setelah user menerima undangan, administrator menambahkan profil dengan role editor melalui SQL. Pengiriman undangan tidak dilakukan dari browser agar service_role key tetap rahasia. 

insert into public.profiles(id,display_name,role)
values ('AUTH_USER_UUID','Nama Editor','editor');
